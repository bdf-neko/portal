# 自己的入口網站

一個用 PHP 就能架的繁體中文入口頁：搜尋、分類連結、行事曆、上方捷徑。站名和連結都在 `config.php`，複製一份就能變成你自己的站。

不需要資料庫，也不需要註冊任何 API 金鑰。

## 架設

需要 PHP 8.0 以上（含 curl）。

```bash
bash setup.sh
```

或是直接：

1. 把這個資料夾放到網站目錄。MAMP 的話就是 `htdocs` 裡的一個資料夾。
2. 編輯 `config.php`。
3. 用瀏覽器打開 `index.php`。

想先在自己電腦看：

```bash
php -S 127.0.0.1:8080
```

然後打開 <http://127.0.0.1:8080>。

## 改成你的站

`config.php` 裡這幾項最常改：

| 項目 | 作用 |
| --- | --- |
| `site_name` | 站名。上方中間預設用文字顯示，建議短一點。 |
| `tagline` / `description` | 網頁標題與說明。 |
| `logo_path` | 留空就用文字。要放圖就把檔案放到 `img/`，例如 `img/logo.png`。 |
| `nav_links` | 上方 8 個捷徑。建議維持 8 個。 |
| `categories_primary` / `categories_secondary` | 主區塊的分類連結。 |
| `feature_links` | 搜尋框左右的文字連結。留空就不顯示。 |
| `tools` | 右側「工具」下拉選單。 |

訪客在自己的瀏覽器裡改的上方捷徑，只存在那台瀏覽器，不會寫回伺服器。按設定裡的「恢復預設」會回到 `config.php` 的清單。

## 這個版本拿掉了什麼

- 即時新聞、天氣、熱門關鍵字
- 菜包服務（祈願、豆友、星座、討論板等）與相關圖示
- 站點專用的 logo、插圖、頁尾徽章、流量統計
- 會員系統與討論板（正式站仍留在原本的專案，沒有放進這份公開版）

搜尋建議會經由 `api_handler.php` 轉問搜尋引擎，不需要金鑰。行事曆的國定假日在 `js/holidays.js`，農曆由 `lunar.php` 計算。
