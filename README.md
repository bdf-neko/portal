# 自己的入口網站

用瀏覽器打開 `index.html` 就能用。站名和連結都在 `config.js`。

要放到網路上，把整個資料夾放到任何靜態空間即可。

## 改成你的站

| 項目 | 作用 |
| --- | --- |
| `site_name` | 站名，用在網頁標題和頁尾。 |
| `tagline` / `description` | 網頁標題後半與說明。 |
| `nav_links` | 上方捷徑，左右各 5 個，共 10 個。 |
| `categories_primary` / `categories_secondary` | 主區塊的分類連結。分隔線寫 `["|"]`。 |
| `feature_links` | 搜尋框左右的文字連結。留空就不顯示。 |
| `tools` | 右側工具區塊，每一組各成一塊。 |

訪客在自己的瀏覽器裡改的上方捷徑，只存在那台瀏覽器。按設定裡的「恢復預設」會回到 `config.js` 的清單。

搜尋建議直接向搜尋引擎詢問。行事曆的農曆在瀏覽器裡計算。
